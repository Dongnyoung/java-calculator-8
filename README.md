# 문자열 덧셈 계산기

## 구현할 기능목록
***
**클래스 단위로 기능을 정의함.**

### 계산기 (Calculator)

- 계산기를 작동시킨다

### 입력받는 클래스 (Input)
- 사용자로부터 입력을 받는다

### 입력값 검사기 클래스 (Validator)
- 커스텀구분자 규칙에 해당하는지 체크한다
  - 커스텀구분자 ("//구분자\n") 규칙에 맞는지
  - 허용된 구분자 외의 구분자 사용했는지
  - 잘못된위치나 비어있는값 검증
    
### 파서 클래스 (CommaColonParser,CustomParser)

- 입력받은 문자열을 파싱한다. 
  - 1)쉼표, 콜론 파서 - "[,:]" 규칙 설정
  - 2)커스텀 파서 - "//",'\n' 규칙 설정
- 파서 인터페이스로 추상화한다.

### 합 클래스 (Add)
- 파싱된 문자열을 더한다.

### 결과출력클래스 (Output)
- 더한 값을 출력한다.
